## 🎨 Capturing Extension Screenshots on Windows

1. Load unpacked extension in Google Chrome (`chrome://extensions` -> Load Unpacked).
2. Click the **PhishShield AI** icon on the desired website.
3. Press `Win + Shift + S` on Windows to capture a focused crop of the popup (380px wide).
4. Save the image into `assets/screenshots/` with the filename listed in the table above.
